# Revive

Revive is a two-part web application that helps users build healthier habits and recover from addictive behaviors through tracking, journaling, and AI-guided recovery plans.

This repository contains two main components:

- `frontend/` — the React + Vite web client (UI, onboarding, daily check-ins, AI chat)
- `backend/` — the Node.js + Express API (Supabase integration, auth, AI services, data storage)

Quick links:

- Frontend docs: frontend/README.md
- Backend docs: backend/README.md

Quick start (development):

```bash
# Start the backend
cd backend
npm install
npm run dev

# In a second terminal: start the frontend
cd frontend
npm install
npm run dev
```

See the per-component README files for full setup, environment variables, and deployment instructions.
